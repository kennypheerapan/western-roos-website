The homepage uses selected, web-optimized derivatives of supplied United Softball Club photography from /public/media/club/united. The original JPEGs remain unchanged in /public/images/club/united.

All homepage references are centralized in src/config/media.ts, including Hero, News, Gallery, Beyond the Diamond and Join. That file also controls descriptive alt text, desktop and mobile focal positions, responsive image sizes and Hero preload. Fixed-aspect-ratio containers prevent layout shifts.
